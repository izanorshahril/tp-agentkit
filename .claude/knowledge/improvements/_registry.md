# Improvement Reports Registry

For the framework that defines when patterns graduate into durable knowledge or rules, see `../continuous_improvement.md`.

This folder contains improvement reports generated by the Quality Agent. These reports capture constructive feedback from user interactions that could improve the AgentKit template.

> Note: These reports are temporary and not verified knowledge.

## How Reports Are Generated

1. During task execution, Quality Agent monitors for constructive feedback
2. Actionable feedback is logged to activity reports
3. Feedback applicable to AgentKit is compiled into improvement reports
4. Reports are saved with unique names: `[usecase]_[YYYYMMDD].md`

## Report Status

| Status | Meaning |
|--------|---------|
| **new** | Fresh report, not yet reviewed |
| **reviewed** | Maintainer has reviewed |
| **integrated** | Changes incorporated into AgentKit |
| **archived** | Declined or obsolete |

## For Maintainers

To integrate improvements:
1. Review reports in this folder
2. Identify actionable improvements
3. Manually update core files (AGENTS.md, agents/*.md, etc.)
4. Mark report as `integrated` or `archived`
